# JIB Pre-order Portal

ระบบแจ้งความต้องการสินค้าสำหรับสาขา พร้อมหลังบ้านสำหรับจัดสรรและบันทึกการส่งสินค้า บน Cloudflare Workers และ D1

## ความสามารถ

- นำเข้าข้อมูลสาขา 22 สาขาไว้ในฐานข้อมูลแล้ว
- สร้างบัญชี `um` และบัญชีสาขา `JIB{รหัสสาข}` อัตโนมัติ พร้อมบังคับเปลี่ยนรหัสผ่านในการเข้าใช้ครั้งแรก
- ผู้ดูแลเพิ่ม แก้ไข ปิดชั่วคราว และเลิกใช้งาน Part ได้
- นำเข้า Part จาก Excel ที่มี `Product`, `Product Name`, `Sell Price`
- สาขาระบุชื่อลูกค้า รุ่นสินค้า และจำนวนที่ต้องการ โดยไม่มีโควต้า
- สาขาแก้ไขหรือยกเลิกรายการได้ก่อนเริ่มจัดสรร
- ผู้ดูแลจัดสรรสินค้าเต็มจำนวนหรือบางส่วน และบันทึกการส่งพร้อมวันเวลาและผู้ทำรายการ
- หน้ารายงานแบบตาราง ค้นหา กรองช่วงวันที่/สถานะ และเรียงตามเวลาที่แจ้งได้
- ส่งออก Excel ตามตัวกรอง โดยแยกหนึ่ง Part ต่อหนึ่งบรรทัด
- เก็บข้อมูล Part และราคาตามเวลาที่สาขาจอง เพื่อรักษาประวัติ

## Deploy

1. ติดตั้ง dependencies: `npm install`
2. เข้าสู่ระบบ Cloudflare: `npx wrangler login`
3. สร้างฐานข้อมูล: `npx wrangler d1 create jib-preorder`
4. นำ `database_id` ที่ได้มาแทน `REPLACE_WITH_D1_DATABASE_ID` ใน `wrangler.jsonc`
5. deploy Worker: `npm run deploy`
6. รัน migration จริง: `npm run db:remote`

ก่อนเปิดเว็บครั้งแรก ให้กำหนดรหัสเริ่มต้นด้วย `npx wrangler secret put INITIAL_PASSWORD` ระบบจะสร้างบัญชีเมื่อมีการเปิดใช้งานครั้งแรก และบังคับให้ทุกบัญชีเปลี่ยนรหัสผ่านทันทีหลังล็อกอิน. ไม่ควรส่งรหัสผ่านผ่านแชตหรือเก็บไว้ใน Git.
